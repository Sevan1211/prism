# Owner reading trial

**Status:** participation approved 2026-09-04; prepared, not started.
**Evidence label:** Experimental. This is an individual product-learning exercise,
not a powered study, preregistration, diagnosis or general efficacy claim.

## Question

Does a detailed, source-grounded PRISM reading document help the owner explain and
apply unfamiliar material seven days later, with acceptable time and effort,
compared with reading the original source?

The current product comparison is original Source Reader versus the approved
reading document with source inspection and learner-requested revision. TSR and
automatic pacing are outside this trial. Their separate research design remains
in the [validation plan](VALIDATION_PLAN.md).

## Smallest useful run

Use two pairs of fresh passages, roughly 800–2,000 words each as a **project design
choice**, matched as closely as practical on difficulty, prerequisites and conceptual
load within each subject. Use different passages across conditions: rereading the
same material would contaminate the comparison. Avoid material already studied
during reference-lesson QA; if prior exposure is unavoidable, record it and treat
that session as usability-only.

Before any study, freeze the source version/hash, exact ranges, concept coverage,
assessment prompts, source-grounded scoring notes and condition assignment.
Pair one uses Source then PRISM; pair two reverses the order. Randomly assign the
two passages within each pair to those positions. Matching and four sessions cannot
remove all difficulty or order effects; report those limits instead of causal certainty.

1. Record prior familiarity and the intended outcome. Take a short prerequisite check
   that does not reveal the target answers. Postpone passages requiring instruction
   in missing prerequisites rather than treating that mismatch as a product failure.
2. Read naturally and allow breaks, original-source inspection and rewinds. In PRISM,
   allow the normal revision interaction. Record agent help and revision time. Use
   equivalent note-taking rules in both conditions; do not hide extra assistance.
3. Immediately afterward, close the source/lesson and answer literal, inferential and
   application questions. Record workload, fatigue and usability separately.
4. At approximately 24 hours, then seven days from each study session, answer alternate
   explanation/application prompts without the material open. Record actual delay,
   intervening study and missing sessions. Do not count a missing result as zero.
5. Withhold answer feedback until the final delayed check so feedback does not become
   an uncontrolled second lesson. Record the retrieval exposure from earlier checks;
   both conditions receive the same schedule.

Do not impose a target learning time that truncates the selected scope. Record total
elapsed study time, active study time, breaks, setup/generation wait, source inspection,
agent conversation and revision time separately. Report first-use cost and reopened
lesson cost separately; never hide generation effort outside a speed claim.

## Assessment blueprint

For each passage prepare two literal questions, two inference questions and one new
application case, with alternate forms for the two delayed checks. This count is a
small-trial design choice, not a validated assessment instrument. Include exact
terminology, symbols or quantities when the source requires them. Match each scoring
criterion to a source span and freeze it before viewing the learner's answers.

Use 0 = absent/incorrect, 1 = partly correct with an important gap, 2 = correct and
adequately justified for each criterion; record specific misconceptions separately.
Score delayed answers with condition labels hidden where feasible, then review any
agent scoring with the source. Agent judgments are untrusted until checked.

## Decision after the run

Compare each outcome beside time; do not collapse everything into one speed score.
Investigate any consequential fidelity error first. Better immediate answers alone
are insufficient. If PRISM improves delayed explanation but takes longer, show both.
If it saves time while delayed application gets worse, record the tradeoff and fix
the relevant teaching gap. With this small individual run, retain observations and
revision decisions without publishing numerical learning-gain claims.

Calendar dates begin only when actual reading starts. Participation approval does
not schedule reminders or imply any delayed measurements have occurred.
