## Human quality rubric

Review source and lesson side by side. For each section record: definitions retained;
reasoning and causal steps taught; examples and intermediate reasoning preserved;
qualifications/negation/quantities correct; visuals legible and supported; added
analogies labeled; omitted material disclosed; prose useful without reconstructing
meaning from disconnected blocks. A known consequential error or missing substantive
idea blocks acceptance regardless of passing software checks.

Record strengths and specific fixes, not only a numeric score. Finish with a fresh
user who can find the original, explain the agent requirement, create a request,
review scope, read, request clarification and reopen their work without developer help.
