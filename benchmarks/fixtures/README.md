This PDF is a development regression fixture, excluded from the production build.
The prior automatic sample installer and prewritten lesson have been removed. Any
new lesson or crop is created by an agent through WebMCP after learner approval,
with its own source attribution. The released library starts empty.

The licensed Computer Networks file is intentionally versioned for reproducible
parser regression tests. It is never installed in a learner's library or shipped
in the website archive. Other local PDFs, including the old unused synthetic
primer, are ignored by Git.
